# AI Engineering Mastery (90-Day Tracker)

Welcome to the **AI Engineering Mastery** repository! This repository serves as a practical, code-first 90-day transition roadmap from traditional Software Engineer to AI Specialist.

## 🚀 The Journey

The core curriculum is structured to move progressively from the absolute fundamentals of LLMs into production-grade orchestration and deployment:

*   **Phase 1:** AI Foundations & LLM Fundamentals (Days 1–14)
*   **Phase 2:** Vector Databases & RAG Foundations (Days 15–28)
*   **Phase 3:** Advanced RAG & Agentic AI (Days 29–42)
*   **Phase 4:** Agent Orchestration & Multi-Agent Systems (Days 43–56)
*   **Phase 5:** Evaluation, Observability & Multimodal AI (Days 57–70)
*   **Phase 6:** Cloud Deployment, MCP & Context Engineering (Days 71–84)
*   **Phase 7:** System Design, Voice AI & Career Prep (Days 85–90)

## 🛠️ Core Technology Stack

This project focuses heavily on modern, production-ready AI engineering tools:
*   **Orchestration & Agents:** LangChain, LangGraph, deepagents
*   **Vector DB:** Qdrant
*   **Evaluation & Tracing:** Ragas, Weights & Biases (W&B), LangSmith
*   **Inference & Deployment:** vLLM, Docker, AWS AgentCore
*   **Advanced Patterns:** Model Context Protocol (MCP), DSPy, LoRA fine-tuning (Unsloth)

## 📂 Repository Structure

## 💡 The "Study-Build-Review" Cycle

This roadmap relies heavily on practical application:
1.  **Understand:** Grasp the theory and architectural patterns.
2.  **Implement:** Write the code (e.g., building attention from scratch, setting up Qdrant).
3.  **Review:** Commit your code and reinforce knowledge through peer review or documentation.
