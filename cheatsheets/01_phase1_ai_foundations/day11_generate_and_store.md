# Day 11: Text Embeddings & Cosine Similarity

## Concise Summaries
Embeddings transform text into dense numerical vectors, allowing computers to measure semantic meaning. `sentence-transformers` is an efficient library to compute these vectors. Cosine similarity measures the angle between two vectors to determine how semantically similar the original texts are.

## Code Snippets

```python
from sentence_transformers import SentenceTransformer
from sentence_transformers import util

# 1. Load a pre-trained embedding model
# 'all-MiniLM-L6-v2' is fast, small, and well-balanced for general use cases.
model = SentenceTransformer('all-MiniLM-L6-v2')

# 2. Define sentences to encode
sentences = [
    "The cat sits outside",
    "A man is playing guitar",
    "I love dogs",
    "The new movie is awesome",
    "The feline is resting outdoors"
]

# 3. Generate embeddings
# This creates a dense vector (e.g., length 384) for each sentence
embeddings = model.encode(sentences)

print(f"Number of sentences: {len(sentences)}")
print(f"Shape of embeddings array: {embeddings.shape}")
print(f"Length of a single embedding vector: {len(embeddings[0])}")

# 4. Compute Cosine Similarity
# Let's compare "The cat sits outside" (index 0) with "The feline is resting outdoors" (index 4)
emb_1 = embeddings[0]
emb_2 = embeddings[4]
emb_3 = embeddings[1] # "A man is playing guitar"

# util.cos_sim returns a tensor with similarity scores (between -1 and 1, usually 0 to 1 for text)
sim_1_2 = util.cos_sim(emb_1, emb_2)
sim_1_3 = util.cos_sim(emb_1, emb_3)

print(f"\nSimilarity ('The cat sits outside' vs 'The feline is resting outdoors'): {sim_1_2[0][0]:.4f}")
print(f"Similarity ('The cat sits outside' vs 'A man is playing guitar'): {sim_1_3[0][0]:.4f}")

# 5. Compute similarities across all pairs efficiently
cosine_scores = util.cos_sim(embeddings, embeddings)

# Example: finding the highest similarity pair (excluding self-comparisons)
pairs = []
for i in range(len(cosine_scores)-1):
    for j in range(i+1, len(cosine_scores)):
        pairs.append({'index': [i, j], 'score': cosine_scores[i][j]})

# Sort pairs by highest similarity
pairs = sorted(pairs, key=lambda x: x['score'], reverse=True)

print(f"\nTop similarity pair: '{sentences[pairs[0]['index'][0]]}' & '{sentences[pairs[0]['index'][1]]}'")
print(f"Score: {pairs[0]['score']:.4f}")
```

## Key Concepts
- **Embedding / Vector**: A dense array of floating-point numbers representing the semantic meaning of text.
- **Model (`all-MiniLM-L6-v2`)**: A specific neural network architecture pre-trained on vast amounts of data to output meaningful text embeddings.
- **Dimensionality**: The size of the output vector (e.g., 384 dimensions for MiniLM). Higher dimensions can capture more nuance but require more compute/storage.
- **Cosine Similarity**: A metric used to measure how similar two vectors are. Values range from -1 (completely opposite) to 1 (identical). In practice for text, values are usually between 0 and 1.
- **`model.encode()`**: The primary function to convert raw string inputs into vectors using `sentence-transformers`.

## Common Gotchas
- **Model Choice and Dimensionality Match:** The dimension of the vector depends entirely on the model you use (e.g., 384 vs 1536). You cannot compute similarity between embeddings generated by *different* models because they live in different semantic spaces.
- **Loading Time & GPU Availability:** `SentenceTransformer` models can be slow to initialize. If possible, ensure PyTorch is installed with CUDA support to leverage GPU acceleration, otherwise `encode()` runs on the CPU.
